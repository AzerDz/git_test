# Advanced Scientific Calculator

Dark-themed calculator with glassmorphism design.

## Features
- Scientific functions (sin, cos, tan, log, ln, √, ^, !, π, e)
- Keyboard support (0-9, operators, Enter, Escape, Backspace, h)
- History panel (localStorage, click to reuse answers)
- Copy result with toast notification

## Run
```bash
python3 -m http.server 8000
```
Then open `http://localhost:8000`

## Tech
HTML + Tailwind CSS + Vanilla JS
